业务代码里取当前用户 & 数据变了怎么办

前者一行代码，后者零代码
取当前登录用户 UserContextHolder.require()
拦截器鉴权后自动注入上下文，任意 Controller 一行拿到 uid / 姓名 / 机构 / 角色 / 权限码（页面头部即它的可视化）。
@GetMapping("/me")
public UserContext me() { return UserContextHolder.require(); }
尚未调用。
缓存自动刷新（钩子通知，业务零代码）
认证中心改了数据不用管——starter 收到签名通知后自动回源刷新缓存，业务代码永远读到的都是新数据。
认证中心改数据管理员改用户 / 机构 / 角色
→
签名通知推送HMAC-SHA256 防伪造防重放
→
starter 自动刷新验签后立即回源回填缓存
→
业务无感知下次读取即新数据
